# ALPHA Chat

تطبيق Android للدردشة مع ALPHA باستخدام Groq، مع الحفاظ على التصميم الحالي وإضافة تجربة محادثة أقرب لتطبيقات الدردشة الحديثة.

## ما تم تحسينه

- محادثة متعددة الرسائل مع حفظ سجل المحادثة محليًا.
- ربط السياق السابق بالرسائل الجديدة مثل: «عدله»، «السابق»، و«نفس الكود».
- بث الرد أثناء التوليد بدل انتظار الرد كاملًا.
- عرض Markdown بشكل أفضل: عناوين، **نص مهم**، وكود منسق.
- إزالة علامات ``` من العرض وتحويل الكود إلى كتلة واضحة.
- زر **نسخ الكود 📋** ينسخ محتوى جميع كتل الكود بدون علامات Markdown.
- دعم إرفاق الصور وتحليلها عبر نموذج الرؤية.
- الاحتفاظ بالتصميم والألوان والواجهات الأساسية الموجودة.
- مفتاح Groq يبقى في Railway ولا يوضع داخل تطبيق Android.

## Railway

أضف متغيرات البيئة:

```text
GROQ_API_KEY=...
GROQ_MODEL=openai/gpt-oss-20b
GROQ_VISION_MODEL=qwen/qwen3.6-27b
GROQ_TEXT_MAX_TOKENS=32768
GROQ_VISION_MAX_TOKENS=16384
PORT=8080
```

الأفضل عدم وضع `GROQ_API_KEY` داخل GitHub أو داخل APK.

## Android

عنوان الـ API موجود في:

`app/build.gradle`

غيّر `API_BASE_URL` فقط إذا غيّرت مشروع Railway.

## تشغيل Backend

```bash
cd backend
npm install
npm start
```
