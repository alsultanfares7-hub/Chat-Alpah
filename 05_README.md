# ALPHA

Private AI Android app.

## Build
The GitHub Actions workflow builds a debug APK automatically.

1. Open GitHub Actions.
2. Open **Build Alpha APK**.
3. Run the workflow, or push a commit.
4. Download the `Alpha-debug-apk` artifact.

## Security
Never put a real AI API key inside the Android app or GitHub repository.
Connect a real AI provider through a secure backend.
